# Oráculo Cultural

Coleta obras culturais e organiza comparáveis para análise contábil a valor justo.


## Scrapers ativos

- ArtSoul
- Blombo
- Gagosian
- Saatchi Art

## Como abrir

No Windows, dê dois cliques em:

`Iniciar_Oraculo_Cultural.bat`

## Alteração desta versão

Apenas a aba **Comparativo** foi aprimorada:

- imagem da obra selecionada em destaque;
- resumo da obra selecionada com preço, técnica, dimensões e ano;
- filtros adicionais de similaridade;
- tabela com barra de progresso de similaridade;
- listagem das obras similares em ordem decrescente;
- cards com imagem das obras similares, pontuação geral e pontuação por critério.

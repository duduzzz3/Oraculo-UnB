# Relatório v15

## Ajustes feitos

1. A metodologia do comparativo foi detalhada com explicação dos critérios, pesos e leitura dos níveis de similaridade.
2. A coleta manual agora permite marcar o preço como **Sem informação**.
3. O rol de técnicas foi ampliado de forma objetiva, incluindo categorias como Xilogravura, Linogravura, Água-forte, Água-tinta, Ponta-seca, Monotipia, Gravura em metal, Tapeçaria, Bordado, Instalação e outras.
4. A normalização de técnica foi ajustada para reconhecer o rol ampliado.
5. O botão de atualização da cotação do dólar agora também atualiza o registro de data e hora da última atualização, inclusive quando a API falha e o sistema usa a cotação em cache.

## Observação

Não foram alterados scrapers, coleta automática, banco de dados, acervo, layout geral ou demais abas.
